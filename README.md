# RM 출결 (rm-check)

라이언멤버스 강사용 모바일 출결 웹앱 (정적 프런트엔드).

카톡·잔디 링크를 누르면 앱처럼 바로 열리고, 원탭으로 출결을 저장합니다.
링크는 강사별이며 `#t=<개인 토큰>` 형태로만 전달됩니다.

## 구성

- `index.html` — 화면 (스켈레톤 + 즉시 렌더, 모바일 퍼스트)
- `app.js` — 앱 로직 (로그인 없는 토큰 API 호출, 낙관적 저장, 로컬 캐시)
- `manifest.webmanifest`, 아이콘 — 홈 화면에 추가했을 때 앱처럼 동작

## 동작

1. 열리면 localStorage에 저장된 직전 화면을 즉시 그리고, 뒤에서 최신 데이터를 받아 갱신합니다.
2. 카드의 `출석 / 정상취소 / 당일취소 / 무단결석`을 누르면 즉시 저장됩니다. 메모는 선택입니다.
3. `⋯`에는 학생명 연결, 수업 아님, 일정변경, 졸업 처리가 있습니다.
4. 기록 탭에서 최근 7일/30일 기록과 메모 미입력 항목을 볼 수 있습니다.
5. `#t=토큰&filter=missing`으로 열면 미입력 수업만 보여 줍니다.

## 보안

이 저장소에는 어떤 개인정보도 두지 않습니다. 강사 토큰·시트 ID·캘린더 ID는
저장소에 저장하지 않으며, 데이터는 각 강사의 토큰으로 인증된 백엔드에서만 응답합니다.
